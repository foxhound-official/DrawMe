# DrawMe

Небольшой графический редактор для Windows, написанный на C++/CLI с использованием Windows Forms.

Проект позволяет создавать изображение на холсте, рисовать мышью различными инструментами, менять цвет и размер кисти, очищать холст и сохранять результат в распространенных графических форматах.

## Возможности

* рисование мышью;
* создание холста заданного размера;
* стандартный и пользовательский размер холста;
* настройка цвета кисти;
* настройка размера кисти;
* рисование линий;
* рисование треугольников;
* рисование кругов;
* рисование точек;
* рисование квадратов;
* очистка холста;
* сохранение изображения;
* изменение размера рабочей области.

## Инструменты рисования

В текущей реализации предусмотрено несколько типов кисти:

| Инструмент  | Описание                                          |
| ----------- | ------------------------------------------------- |
| Линия       | Рисование произвольной линии мышью                |
| Треугольник | Рисование треугольника                            |
| Круг        | Рисование эллипса                                 |
| Точка       | Рисование небольшой фигуры вокруг позиции курсора |
| Квадрат     | Рисование прямоугольника                          |

Также в коде предусмотрен дополнительный режим кольца.

## Интерфейс

Основное окно состоит из:

* панели меню;
* панели инструментов;
* области рисования;
* панели настроек кисти;
* панели создания нового проекта;
* строки состояния.

Основная область рисования реализована через `PictureBox`, а непосредственно отрисовка выполняется средствами `System::Drawing::Graphics`.

## Работа с холстом

При запуске создается белый холст.

Размер нового проекта можно задать вручную. В интерфейсе доступны два режима:

* стандартный размер;
* пользовательский размер.

Для пользовательского размера доступны отдельные поля ширины и высоты.

Размеры ограничиваются размерами экрана.

## Настройка кисти

По умолчанию используется:

```text
Цвет: черный
Размер: 10
Тип: линия
```

Цвет изменяется через стандартный `ColorDialog`.

Размер кисти задается через `NumericUpDown`, после чего создается новый объект `Pen` с выбранными параметрами.

## Управление

Рисование выполняется с помощью мыши.

При нажатии левой кнопки мыши начинается рисование. Во время перемещения курсора координаты добавляются в список точек, после чего `PictureBox` перерисовывается.

Для линий используется последовательность точек:

```text
MouseDown
    ↓
MouseMove
    ↓
добавление Point
    ↓
Graphics::DrawLines()
    ↓
MouseUp
```

Другие инструменты используют текущую позицию курсора для построения геометрической фигуры.

## Работа с файлами

В меню доступны операции:

* создание нового холста;
* сохранение изображения;
* очистка холста.

Для сохранения используется `SaveFileDialog`.

Поддерживаемые форматы:

```text
.bmp
.jpg
.png
```

Изображение сохраняется как `Bitmap`.

## Ограничения

Проект является небольшим учебным графическим редактором.

Текущая реализация имеет ряд ограничений:

* отсутствует полноценная система слоев;
* отсутствует история действий Undo/Redo;
* отсутствуют инструменты выделения;
* отсутствует масштабирование изображения;
* нет отдельной модели документа;
* сохранение выполняется непосредственно из текущего `Bitmap`;
* набор инструментов ограничен реализованными типами кисти.

## Назначение проекта

`DrawMe` представляет собой практическую реализацию простого графического редактора с использованием C++/CLI и Windows Forms.

Основная часть проекта сосредоточена на обработке событий интерфейса, работе с мышью и непосредственной отрисовке графики через `System::Drawing`.

Проект также демонстрирует взаимодействие нативного C++-кода с .NET Framework через C++/CLI.
